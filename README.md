# The Orbit — Wednesday 18 November 2026 in one image

A make.fun entry for **news-image-20261118** ("Sum up 18 November's world news
in one image", $250).

`main.ts` (Node 22, standard library only, no network) draws a dense
newspaper front page of the day's world news pixel by pixel — its own PNG
encoder, rasteriser and 5x7 bitmap typeface — and writes it to
`/output/entry.png` (locally: `MAKEFUN_OUTPUT_DIR=out node main.ts`). The
drawing is fully deterministic: two runs write byte-identical files.
